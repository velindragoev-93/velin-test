How Dealers Add the AI Server to an Installed Site

Adding the AI Server to an installed site takes five steps, and none of them require replacing a camera.

  1. Pick an installed site. Start with a customer that already has IP cameras on the wall.
  2. Connect the cameras. The cameras connect to the AI Server over an encrypted, outbound-only link, with no port forwarding and no per-camera network setup.
  3. Configure remotely. Set up and tune detections through the Dealer Portal, without a site visit.
  4. Arm the alarm zones. Pair the AI Server with the CHeKT Video Control Panel so each detection becomes a real alarm zone with an arming schedule.
  5. Bill through your monitoring center. The alarm lands in the automation platform your monitoring center already runs, and you add a recurring monitoring fee to a job you have already closed.

Frequently Asked Questions About the AI Server

What is the CHeKT AI Server?

The CHeKT AI Server is an AI video analytics appliance that adds deep learning detection to existing IP cameras and sends each detection to a monitoring center as a verified video alarm through the CHeKT Video Control Panel.

Can dealers add AI video analytics to cameras that are already installed?

Yes, dealers can add AI video analytics to installed cameras with the AI Server. It works with existing IP cameras from any brand, so nothing is ripped out, rewired, or replaced. CHeKT to confirm: any IP camera, or ONVIF only?

How do dealers earn recurring revenue with the AI Server?

Dealers earn recurring revenue with the AI Server by adding a monitoring fee to systems they have already installed, billed through the monitoring center they already use. CHeKT does not sell monitoring, so it does not compete with its dealers.

What is a verified video alarm?

A verified video alarm is an alarm event that reaches the monitoring center with live video, so an operator can confirm what is happening, issue a talk-down, and request dispatch.

Does the AI Server work with my monitoring center's software?

The AI Server works with the automation platform your monitoring center already runs. The CHeKT Video Control Panel connects to eighteen-plus automation platforms.

Does the AI Server require changes to the customer's network?

No, the AI Server does not require port forwarding. It connects over an encrypted, outbound-only link, so nothing on the customer's network is reachable from the internet.

Context for the decisions above. None of this goes on the page.

Page role

Model numbers, channel counts and specifications live on /ai-server-ckta1612/. We recommend keeping them off this page and linking to the product page instead.

Claims we could not verify from public sources

Please confirm each of these before publishing. They are marked amber above.

  • "generating RMR in days, not weeks" (Faster Time to Bill)
